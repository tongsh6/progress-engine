# Documentation

本目录保存 ProgressEngine 的源文档章节，按项目结构组织，而不是按单一长文顺序堆放。

## 分组

- `00-overview/`：执行摘要、愿景、核心方法论。
- `01-state-engine/`：Project State、State Gap、Target State、核心对象和数据模型。
- `02-bootstrap-workflows/`：从 0 启动角色流水线、典型工作流。
- `03-system-design/`：系统架构、模块边界、CLI 与交互设计。
- `04-protocols/`：Intervention、Fresh Context、Evidence、Change Event、State Delta、Guarded Spiral 等协议。
- `05-delivery/`：MVP、路线图、质量、风险、实施计划。
- `06-business-reference/`：商业化、术语表、自检与开放缺口。
